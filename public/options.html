Google Sheets recommended

One row per application. Track the Status in your sheet.

Off
  1. Create a Google Sheet. Open Extensions → Apps Script.
  2. Click Copy script, paste it there (replace everything) and save.
  3. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Authorize it.
  4. Paste the Web app URL below and click Save.

Other app (webhook)

Excel Online, Notion, Airtable… through Zapier, Make, n8n or Power Automate.

Off

Create a flow that starts with “Webhook / When an HTTP request is received”, then paste its URL. Sabi sends one JSON POST per application, signed with the header X-Sabi-Signature (see docs/integrations.md).

Tokens and URLs are saved only in this browser and are not included in the JSON backup.
